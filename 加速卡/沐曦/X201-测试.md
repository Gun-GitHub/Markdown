
| 描述           | 指令                          |
| ------------ | --------------------------- |
| 查看GPU看板      | $ ht-smi                    |
| 查看版本号        | $ ht-smi –show-version      |
| GPU 利用率      | $ ht-smi –show-usage        |
| GPU 显存使用     | $ ht-smi –show-memory       |
| GPU 查看 SN    | $ ht-smi –show-eeprom       |
| GPU 进程       | $ ht-smi –show-process      |
| GPU 电流、电压、功耗 | $ ht-smi –show-pmbus-power  |
| Marslink 拓扑  | $ ht-smi topo -m            |
| GPU 频率       | $ ht-smi –show-clocks all   |
| 设备列表         | $ ht-smi -L                 |
| 看板每隔 2s 刷新   | $ ht-smi –l 2000            |
| GPU 温度       | $ ht-smi --show-temperature |
